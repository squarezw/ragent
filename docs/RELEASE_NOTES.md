# 发布说明

## 0.5.1 - 2026-08-29

> 本版的主线是 **积分计费**
> 次线是**技能导入**——技能不必再一个字段一个字段地手填。

### 🚀 主要更新

#### ⭐ 积分计费（重点）

- **看得见花了多少**: 每轮回答下方显示消耗的积分；会话详情里能展开到输入/输出 token
- **用量明细**: 新增「用量明细」页，按租户 / 用户 / 会话三层下钻，可导出 CSV
- **计费系数**: 模型、技能、工具各自的系数在系统设置里可改；没设过的条目会标出「按默认值」，
  免得「明确判定免费」和「新绑忘了设」在账目里长得一样
- **账目口径**: 余额从流水现算而不是存一个可能对不上的数；重复提交靠幂等键在库里挡住，
  不会因为手抖点两次就充两倍

#### ⭐ 技能导入（重点）

- **整个文件夹或 zip 拖进来**: 导入前先展示文件树和逐文件校验结果，不是传完才知道对不对
- **只有一个 SKILL.md 也能导**: 不必为了凑格式建一个空目录
- **先看要求再导入**: 导入前告诉你这份技能需要哪些工具、哪些环境变量、什么运行镜像
- **文件夹上传传的是内容**: 选中一个目录，传上去的是它里面的文件，而不是又套一层同名目录
- **在线改文本资产**: 脚本和参考资料可以直接在页面里改，不用下载改完再传回来

#### 功能增强

- **复制回答**: 消息操作栏新增复制按钮
- **技能按组织筛选**: 技能列表可按租户和部门筛选
- **数字员工按租户筛选**: 数字员工列表新增租户筛选（仅超级管理员可见）
- **可写目录可编辑**: 技能的沙箱可写子目录改为在产物列表旁直接编辑
- **运行镜像如实显示**: 只列出宿主机上真实存在的沙箱镜像，不再列出一个选了会失败的

## 0.5.0 - 2026-08-10

> 本版的主线是 **Skills（技能）**：把「数字员工会什么」从提示词里拆出来，
> 变成可以单独编写、审核、发布、在多个数字员工之间复用的单元。

### 🚀 主要更新

#### ⭐ 技能（重点）
- **独立管理**: 新增「Skill 管理」，一份技能就是一份作业指导书——什么时候该用它、用它的时候怎么做
- **改了不会立刻上线**: 技能分草稿与已发布两份。编辑期间线上仍用旧版，直到审核通过才生效
- **审核流程**: 提交审核 → 管理员批准或驳回（可写理由）；支持并排对照草稿与已发布的差异
- **能跑脚本**: 技能可以带上脚本，在隔离的沙箱环境里运行，用来做表格处理、报告生成这类确定性的活
- **各自的凭据**: 需要密钥的技能由每位使用者自己填，互相看不到，平台不代持
- **绑定与体检**: 把技能绑到数字员工上即可生效；如果它依赖的工具没绑，页面会直接指出来，而不是让技能悄悄不工作

#### ⭐ 用对话创建技能（重点）
- **技能创建助手**: 平台自带一个助手，绑上之后可以直接说「帮我做一个审查合同的技能」，它会带着你写完并提交审核，不用从空白页开始
- **人来把关**: 助手可以起草内容和脚本，但「批准发布」始终由人来点。没批准的内容不会出现在任何对话里，脚本也不会运行

#### 功能增强
- **更名**: 「应用」统一改称「数字员工」
- **技能资产**: 支持在线预览单个文件、一键导出全部
- **跨租户迁移**: 超级管理员可以把技能转到其它租户，用于人员调岗后的归属调整

#### 权限
- **谁能改**: 数字员工和技能，只有创建者本人、超级管理员、本租户管理员可以编辑或删除，其他人只能查看
- **私有内容更严**: 设为私有的数字员工和技能，除超级管理员外其他人不可见
- **自动补依赖**: 绑定技能时会自动补上它需要的工具，并告诉你补了哪些
